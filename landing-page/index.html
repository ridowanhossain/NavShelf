Powerful Capabilities

Designed for Modern Workflow Superpowers

Every feature in NavShelf is engineered to make file management as fast, fluid, and intuitive as browsing the web.

Native Windows 11 Multi-Tab Attachment

NavShelf attaches directly below the tab bar using hardware-accelerated Win32 child positioning. Switch tabs, create new tabs, or reorder them effortlessly without losing your bookmark bar.

Supports Windows 11 (22H2 / 23H2 / 24H2) & Windows 10

Mouse Middle-Click New Tab

Click any bookmark chip with your mouse scroll wheel to immediately spawn that folder in a brand-new tab. Just like Google Chrome and Microsoft Edge!

Live Real-time Theme Sync

Seamlessly auto-detects Windows Dark Mode and Light Mode with instant live updates on open Explorer windows.

Common File Dialogs (#32770)

NavShelf automatically docks to Open & Save dialogs in Photoshop, VS Code, Chrome, and Notepad without blocking UI buttons.

Effortless Drag & Drop

Drag any folder directly from File Explorer and drop it onto the bookmark bar to pin it instantly with automatic icon detection.

Global Hotkey & Clean Exit Integration

Toggle the bar anywhere via Ctrl + Shift + B or exit instantly with the dedicated ✕ button. Runs silently in the system tray with optional auto-start on boot.

Zero Hassle Setup

Up and Running in 3 Seconds

No complicated installers, no registry hacks, and no system file modifications.

01

Download Executable

Download the single NavShelf.exe binary (~108 KB). It is completely portable and requires no admin rights.

02

Run NavShelf

Double-click to launch. NavShelf silently detects open File Explorer windows and mounts the bookmark bar beneath your tabs.

03

Bookmark & Navigate

Drag folders onto the bar, click to jump, or middle-click to spawn new tabs. Press ⚙ to customize colors and icons.
